# Changelog – Root-Ascent Method

All notable changes to the **method specification and repository artifacts** are recorded here.  
Dates are approximate calendar dates of public repo evolution (August 2026).

Format inspired by [Keep a Changelog](https://keepachangelog.com/). Versioning is **method/docs versioning**, not software semver with releases.

---

## [0.4.1] – 2026-08-17

Documentation and prompt **clarity** release (ladder rules unchanged from 0.4; failure modes from multi-model Nobel-series tests incorporated).

### Added

- **What this is not** (README, PROMPT identity block, EXAMPLES failure-mode note): not a numerical optimizer / energy-landscape algorithm; not a field-impact certificate from desk analysis alone.
- EXAMPLES **Case 7** – German heat-pump diffusion 2024–2025 (Manus AI, CASE-SCHEMA, pre-registered structure metric, claim boundaries).
- EXAMPLES **Case 8** – AI protein design vs biosecurity screening (Kimi K3, counter-hypotheses that changed L4).
- CASE-SCHEMA optional fields: `diagnosis_changed_by_rivals`, `expectation`, `evaluation_design`, `claim_boundary`.

### Changed

- PROMPT: identity guard against optimizer homonym; rivals may change diagnosis; claim-boundary rules; optional pre-registration of structure metrics.
- README: negative definition, Cases 7–8 in proof line, 0.4.1 status note.

### Insight locked in

Best “value” of the method is often **preventing a wrong Level-4 lock-in**, not maximizing the count of levers or inventing world-impact percentages.

## [0.4] – 2026-08-17

### Hardened (implemented in executable prompt and mirrors)

- **Case-specific intent** required at the start of every run (no automatic default to “capability–governance gap”).
- **Saturation checklist** before ascending a level.
- **Mandatory counter-hypothesis step** before locking Level 4.
- Explicit evidence discipline: fact / strong pattern / hypothesis.

### Added

- CASE-SCHEMA.md / .de.md, INTENT.md, CHANGELOG.md, landing page v0.4 entry points.
- CONTRIBUTE role-based prompts; AGENTS activation for v0.4.

### Changed

- PROMPT / METHOD / WORKING-PAPER / README dual-language set aligned to v0.4.
