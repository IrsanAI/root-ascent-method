## [0.4] – 2026-08-17

### Hardened (implemented in executable prompt and mirrors)

- **Case-specific intent** required at the start of every run (no automatic default to “capability–governance gap”).
- **Saturation checklist** before ascending a level (claim, evidence, counter-evidence, residual uncertainty).
- **Mandatory counter-hypothesis step** before locking Level 4 (rival explanations, weights, falsification note).
- Explicit evidence discipline: fact / strong pattern / hypothesis.

### Added

- [CASE-SCHEMA.md](CASE-SCHEMA.md) / [CASE-SCHEMA.de.md](CASE-SCHEMA.de.md) – minimal structured fields for comparable runs.

## [0.1] – Genesis (pre-repo / early formalization)

### Emerged from practice

- Investigation starting from unauthorized Flock Safety ALPR camera (Millcreek, Utah).
- Iterative human–AI process crystallized into ladder: incident → patterns → architecture → higher-order cause → levers → operational strategy.
- Core diagnosis pattern: capability systematically scaling faster than governance (candidate structural framing).
- First packaging as reusable method name: Root-Ascent / Causal Ladder.
