# Root-Ascent Method

**Causal Ladder** — From concrete incidents to systemic causes and actionable levers.

**Current version: 0.4** (+ 0.4.1 clarity · **Prompt Factory v0.1**) · AI collaboration.

---

## Why it exists

Most analyses stay at symptoms or drift into speculation. Root-Ascent forces a controlled climb — and a return to action:

**Concrete Incident → Patterns → System Architecture → Higher-Order Cause → Levers → Operational Strategy**

Version 0.4 requires **case-specific intent**, **saturation checks**, and **counter-hypotheses** before locking Level 4.

**New:** Use the method not only as a full analysis run, but as an **intent amplifier** inside other tools (NotebookLM audio, music style fields, agent constraints, mid-chat recalibration) via short **embed snippets**.

→ [PROMPT-FACTORY.md](https://github.com/IrsanAI/root-ascent-method/blob/main/PROMPT-FACTORY.md) · [Deutsch](https://github.com/IrsanAI/root-ascent-method/blob/main/PROMPT-FACTORY.de.md)

## Domain-agnostic

Cases 1–15 span surveillance, AI agents, synthetic media, diffusion, biosecurity, grid costs, digital identity, satellite D2D, housing pricing, transport safety, regional IT value architecture, and more.

## Who it is for

**Primary:** Investigative journalists, independent researchers, civil-society technologists, technology-policy analysts, advanced AI users.  
**Secondary:** Academic researchers, digital-rights orgs, strategic government teams.  
**Tertiary:** Think tanks, OSINT, socio-technical risk professionals.  
**Experimental:** Research labs, agent developers, data journalism, civic technologists.
