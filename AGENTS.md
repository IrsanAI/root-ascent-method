## How to activate (agents)

**Seeded Mode:** Take the supplied concrete starting point → load PROMPT v0.4 → declare case-specific intent → climb the ladder with saturation checks → counter-hypotheses before locking Level 4 → levers and operational strategy.

**Autonomous Mode:** Select a current public case **not** already central in EXAMPLES.md when possible → then same process.

**Minimal activation** (from PROMPT v0.4 compact form):

> Work strictly according to Root-Ascent Method v0.4 (Causal Ladder). At start: declare a case-specific intent (do not auto-default to capability–governance gap). Use seeded material or pick a fresh public case. Ascend only after a brief saturation check. Before locking a higher-order cause, list and weigh rival explanations. Mark facts vs patterns vs hypotheses. Continuously calibrate against intent. When the structural cause is clear enough, develop concrete levers and an operational strategy. Stay disciplined, evidence-oriented, and action-capable.

## Recommended behavior

1. Prefer the prompt (v0.4).  
2. Respect the ladder; saturation before ascent.  
3. Counter-hypotheses before Level-4 lock.  
4. Calibrate against **declared** intent.  
5. Stay grounded to the concrete start.  
6. Descend to levers and strategy.  
7. Contribute new cases via schema when useful.  

**Avoid:** Ignoring constraints; endless ascent; moralization/conspiracy as substitute for structure; presenting speculation as fact; defaulting every diagnosis to the same template.
