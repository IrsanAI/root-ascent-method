## What this is not (read carefully)

Root-Ascent Method is a **socio-technical causal analysis protocol** (incident → structure → levers).

It is **not**:

- a numerical optimizer, gradient method, or energy-landscape algorithm;  
- a license to invent “+X% real-world impact” from a desk run;  
- a replacement for primary sources or domain expertise.

If you find yourself minimizing Rastrigin functions or maximizing k_cat under this name, **stop** — you have left the method. Reload [PROMPT.md](PROMPT.md).
